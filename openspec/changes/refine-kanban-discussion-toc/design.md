## Goals / Non-Goals

Goals：保持原详情框架、头部处理人/状态、原文描述/结果/摘要/四页签、资料栏，解决七项具体问题。给出可预测阅读位置与主动跳转反馈。

第二轮补充用户已明确要求的编辑器样式、材料名称/复制入口与展开收起反馈；来源见requirements.md第二轮原话。本轮仅按要求修改方案/设计稿，未获得方案通过、视觉通过或实现授权。

Non-Goals：不增加通用目录框架、不加库、不重新实现上传/附件渲染/处理人接口，不改历史记录或数据库，不处理风扇根因。视觉稿是模拟互动，发送/资料操作不触及真实服务。

### 2. 编号不等于身份

按完整当前卡片评论集合的 created_at 升序、数值原ID升序生成 id→floor 1…N；只在完整结果成功读取后显示，不拿作者筛选后的数组编号。按时间而非取ID减最小ID，避免跨卡ID缺口和同秒乱序。显示楼层用于楼层头、目录按钮/预览、定位播报、右栏来源；内部data-comment-id、选择、快照、附件、缓存、写入全部仍按原ID。评论正文内用户原文中的#104等不自动改写，CLI/工具返回原ID不变。

计数：评论N是完整当前卡片集合数量（交接与普通讨论均计入），过滤时附“显示K/N”，目录只呈现可见K条，保留原映射。因此未过滤时最大显示楼层=N；过滤可出现跳号但不重新绑定评论。加载失败/不完整时不生成假连续编号。

目前没有单评论删除/隐藏字段与接口；本轮不引入。作者筛选、折叠不是删除。若未来后端实际移除一条，成功全量刷新后按剩余集合重算1…N；明确这种跨数据变更的编号可变，原ID身份稳定。本轮不能承诺删除后编号永久稳定；若未来出现分页/逻辑删除，需独立定义服务端序号/计数合同，不能沿用局部数组冒充全量。

### 3. 主路径与窄屏

进入详情 → 阅读卡片描述/最新交接 → 滚到讨论 → 悬停短横预览 → 点击或Enter定位并展开目标 → 继续手动阅读 → 点击楼层头选择历史资料 → 清空/排序/作者过滤 → 输入文字或粘贴图片 → 沿用原发送/核对恢复路径。

宽屏保留两栏，主栏滚动区与编辑器占满主栏高度，末楼底部留现有间距，编辑器增高自然压缩主栏阅读区而非用猜测padding。右栏独立滚动到附件末项，不再被编辑器挤短。

<=700px沿用现有断点，但用“讨论 / 资料”小型区域切换（区别于评论/活动/运行/日志页签），替代把资料塞到讨论末尾。讨论区有固定编辑器；资料区使用完整高度且无编辑器，不销毁原草稿或已加载内容，回讨论恢复位置。目录仅讨论页签且讨论与可见阅读区相交时显示，不在描述区/活动/日志/资料页悬空。

### 4. 四种状态分开

- activeReadingId：唯一活动阅读楼层；目录aria-current与活动编号指向它。
- locatedId：主动定位目标及定位提示；点击先展开，布局完成再滚至主栏顶部8px，末楼受滚动上限时仍明确标为点击目标。
- previewId：仅鼠标悬停或键盘焦点对应内容，不能改变activeReadingId或历史资料。
- selectedContextId：现有历史上下文选择，只由楼层头和清空/过滤规则修改；跳转、悬停、阅读不修改。

点击短横立即把activeReadingId设为目标并进入“定位锁”。程序滚动、折叠展开、图片加载、窗口/编辑器变化不抢掉定位锁。下一次用户主动引起主栏实际scrollTop变化时释放（wheel/touch/滚动条/PageUp/PageDown/方向键/Space；不是仅收到按键或无位移wheel），开始阅读判定。筛选移除目标、切卡/来源/离开讨论时清理无效锁，不选取别的历史上下文。

阅读判定：只考虑当前可见楼层，阅读视区为主栏滚动区与讨论区域交集。每条score=可见高度/min(本条高度,阅读区高度)。初始无活动取最高score，平分时选交集中心距阅读区中心最近，仍平分按显示顺序。已有活动保持，直到其他条score比它高至少0.15或它完全不可见；切换时使用同样平分规则。超长单楼覆盖视区时score=1，不因为头部不在视区而换楼。该规则基于实际占用与连续性，不是简单固定顶部或中线；阈值是拟定的低风险交互参数，视觉稿可观察，不要求用户选择算法。

性能：生产改动拟复用现有discussionScroller，resize/disclosure观察，scroll按一帧合并、只对可见候选测量；不向整页广播每帧状态，不持续动画。不使用IntersectionObserver精确像素判定的虚假保证：可用其筛候选，但仍需实际边界计算。

### 5. 目录位置与输入

保留讨论左边独立24px轨道/间距，楼层边线不与短横重叠。设讨论自然顶D、主栏阅读边界T/B、相交可见边界Vt=max(T,D)、Vb=min(B,讨论底)。目录高度h=min(240px,Vb-Vt-16px)，不可用高度时隐藏。目录top=max(D,(Vt+Vb)/2-h/2)，并限制在Vb-h以内，最后换成讨论区域内偏移。讨论从下部进入时从自然起点出现，滚动后整体中心到可见中部即停，不到页头；上滚、编辑器变化、讨论展开重算。长目录内部滚动，活动短横变化时只调整内部scrollTop，不滚动外层。

短横维持紧凑视觉，但命中区至少24×24；长列表内部可滚。Tab进入目录，方向键/Home/End在可见条目间移动焦点，Enter/Space定位，焦点预览不抢活动楼层。Esc只关闭预览，焦点留原短横，不能顺带关闭任务。触屏点击直接定位，无需三横总入口；长按预览不是完成任务的前置条件。

预览向讨论内侧弹出，复用现有弹窗边界/主题/短过渡；只当前原文（长内容自身滚动、链接不自动打开）。悬停与焦点都可打开，移出有短延迟以便读长文，Esc关闭；遵守reduced motion，不循环。原附件读取安全路径保留，不在预览内另造文件打开动作。

### 6. 现成方案与选择依据

### 6a. 第二版补充映射与操作规则

| 新反馈 | 当前证据 | 拟改与边界 |
|---|---|---|
| 自动尺寸、不可手动拖动 | 首版模拟稿resize:vertical；产品comment-composer-view.tsx:74已经field-sizing-content/resize-none | 修正模拟稿为自动增高/缩回，最多min(160px,25vh)，超出后编辑区内部滚动；不把已有产品自动尺寸说成缺失 |
| 透明外围、单层框和区分背景 | 附件17圈出模拟稿外层border-top与编辑区边线 | 发表外围无框无填色；仅编辑区保留主题细边线与轻微不同背景，沿用普通会话的平面层次，不复制整个会话控制栏 |
| 文件名及省略、复制只用图标 | drawer.tsx:1036直接把path作为filename，:1040默认CopyButton；attachment.tsx:70-91包裹行可换行且filename为原path | 标签取路径最后一段，单行省略、按钮固定空间；内部路径保持原样，复制完整原路径而非标签；原只读预览/下载行为不变 |
| 第一个ZIP无复制 | 附件15关联附件和全部附件只含预览/下载 | 两类材料行都提供图标复制，ZIP不例外；附件用接口提供的stored_path，不猜下载URL/本机路径，缺路径则禁用并给无障碍原因，不复制错误路径 |
| 展开/收起不清晰 | 首版模拟稿muted色和弱命中范围 | 复用Button textStrong及DisclosureCaret的主题样式：强调色、下划线/状态箭头、清晰焦点，无滤镜模糊；不加多层边框 |

输入、粘贴文字、删空或宽度改变时自然调整编辑高度，切资料再返回仍保留草稿和实际高度。图片及恢复提示独立留在原流程，不改提交快捷键或恢复协议。设计稿JavaScript尺寸逻辑只为独立HTML兼容；产品优先复用原Textarea的field-sizing，不新增通用编辑器。

材料打开、复制、下载是三个独立动作。复制按钮不常驻“复制”文字，也不出现冗余复制提示；保留aria-label以供键盘/读屏识别，成功短暂显示勾号，失败提供可选完整路径供人工复制而不宣称成功。模拟稿的预览/下载只演示反馈，路径/文件内容均标模拟；复制会把模拟完整路径写入剪贴板，需主动点击。不会读真实文件或请求业务服务。同名材料仍使用原身份和原路径，不能因相同basename合并。

普通会话参考use-composer-metrics.ts的实际换行尺寸与边界观察，而非照搬全部聊天状态/共享存储；已有Kanban输入原生自动尺寸和WorkspaceValue的icon CopyButton足以扩展。
CopyButton当前appearance=icon会额外生成Tip；本轮可直接使用其appearance=button、showLabel=false、buttonSize=icon-xs实现只图标无冗余Tip，并通过onCopyError提供人工恢复，不改全局复制组件。attachment.tsx默认把原filename直接给标签，行flex-wrap，因此需在既有附件行调整标签及收缩边界，不只把父栏截断掩盖操作。补充范围无需目录库、剪贴板库或后端迁移。仅有源路径的附加材料和本地附件以原来源安全检查为准；远端路径复制只是文本，不代表本机可打开。

### 6b. 原有选择依据（仍适用）

本项目已有拆分的CommentThread、FloorDirectory、CommentComposer与discussionScroller，足够覆盖布局、折叠、来源固定与写入恢复。仅调CSS不能解决编号/主动定位锁/预览内容；扩展既有组件成本低于引入目录库或另建页面。

外部原始资料：MDN position、Intersection Observer（2026-10-11抓取，来源与片段见调查）；sticky按最近滚动机制祖先，而非自动理解讨论可见区；IntersectionObserver提供异步相交观察，不拥有点击意图或历史资料状态。因此可复用浏览器原生能力，不引新依赖。调查范围仅CSS/可见性方案，没有宣称全市场不存在类似产品。直接使用一般目录库仍需定制状态和身份契约，引入维护/迁移成本，收益不足。

## Risks / Trade-offs

- 窄屏区域切换改变资料访问一步 → 操作稿提供390宽和640×400检查，等待视觉批准。
- 短评论同时全可见时score平分 → 保留已有活动，避免抖动，初次按中心距选取；手动滚动才释放点击锁。
- 过长目录要额外内部滚动 → 24px命中区优先可用性，支持Home/End并保持活动条可见，不压成不可点击像素。
- 编号是展示而非永久身份 → 原ID不动，原文不改，删除不新增；右栏来源统一显示楼层，不误读旧正文引用。
- 首次产品验证需当前安装端真实视图 → 本轮未找到运行桌面，不自动启动；截图与真实源码组件模拟页面只作调查，后续实施须核实客户端运行版本，不能用视觉稿通过替代验收。

## Migration Plan

不涉及数据库/历史ID迁移，当前不执行部署。未来获准实现：保留代码基线，隔离模拟数据验证→准确提交→reviewer审查；另获授权后才安装/重启。回退是恢复获准基线代码/客户端版本，不需要数据恢复，不得因界面回退删除已发评论或附件。

## Validation Plan

视觉稿先验证：宽屏主栏编辑器边界/右栏底部；390×800、640×400；5/40/0楼层；上下滚动/长目录/末楼点击/多楼可见/超长单楼；展开收起/排序/作者过滤；点击锁与实际手动滚动释放；hover不换活动/选择；键盘Home/End/Enter/Esc；reduced motion。保留截图和机器可读检查结果，均标模拟。

第二版追加：实际输入多行与删除/粘贴/改宽后尺寸；低屏上限内部滚动且末楼可读；外层透明无框与单层编辑区背景；长文件名单行省略不挤图标；首ZIP及全部附件复制原路径；无复制文案/冗余提示，成功与失败分开验证；展开/收起颜色、实际内容高度、箭头和键盘焦点。模拟复制成功分支采用隔离剪贴板替身，不冒充系统剪贴板/安装端证明。

未来产品验收：针对已有测试文件最小增补，不跑全量；编号映射与同秒ID、过滤稳定、真实几何滚动和点击锁、动态编辑器高度、侧栏末附件、空/加载错误；回归来源固定附件/Markdown链接禁用/图片粘贴部分成功恢复/处理人/上下文独立；在真实TaskDrawer+隔离API数据的浏览器验证，生产业务DB只读。若需API写入，隔离Kanban home+绝对DB、清除继承board、初始化前断言。测试进程及时停止。
