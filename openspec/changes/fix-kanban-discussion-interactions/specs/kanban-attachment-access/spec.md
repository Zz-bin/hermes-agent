# Spec Delta

## Purpose

让用户从任务详情与交接材料中明确区分打开阅读和保存文件，保证远程附件、来源切换和不可预览类型都不会误读其他设备或自动执行文件，保留可恢复的阅读体验。

## ADDED Requirements

### Requirement: 点击附件打开安全只读预览
系统 SHALL 在用户点击有合法来源路径的附件名称时打开只读预览，而非弹出保存；图片、PDF、文本和Markdown使用对应阅读方式；HTML不得执行脚本、访问网络或触发系统程序。未知二进制不得自动执行。

#### Scenario: 两处附件入口一致
- **WHEN** 用户点击全部附件或交接材料中的图片、PDF、文本或Markdown名称
- **THEN** 打开相应阅读内容，不触发保存，原讨论位置保持，关闭后焦点回到入口

#### Scenario: HTML与未知类型
- **WHEN** 用户点击包含脚本的HTML或不可预览文件
- **THEN** HTML在安全限制下阅读且不执行脚本；未知类型明确提示不能预览并提供保存选择

### Requirement: 打开与保存固定原始来源
系统 MUST 将打开和保存绑定到取得附件详情的连接和身份；不能在切换后改读当前机器或其他身份。打开和保存入口 SHALL 独立。

#### Scenario: 来源切换
- **WHEN** 远程附件显示后用户切换连接或身份并点击打开或保存
- **THEN** 仍读取原来源或明确说明不可用，不读取新连接的同名路径

#### Scenario: 保存或取消
- **WHEN** 用户点击独立保存按钮后完成或取消文件选择
- **THEN** 完成才提示已保存，取消不作为错误或成功，且不改变评论选择

#### Scenario: 不可用或超限
- **WHEN** 缺少合法路径、来源断开、权限不足、文件不存在或超过阅读上限
- **THEN** 禁用无路径入口或给明确错误/限制，允许关闭和适用的重试/保存，不猜测替代来源
